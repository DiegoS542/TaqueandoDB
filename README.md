Nombre del Proyecto: "Taqueando - Sistema de Gestión".

Instrucciones de Instalación:

"Entrar a cd frontend y ejecutar npm install".

"Entrar a cd backend y ejecutar npm install".

Cómo correr el proyecto:

"Para el back: node index.js".

"Para el front: ng serve -o".

Notas importantes: "Recuerden crear su archivo .env en el backend".
